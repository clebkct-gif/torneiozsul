⚠️ REGRA SEMANAL
É proibido jogar mais de 1 vez com o mesmo adversário na semana.
1 Botão Add
  • Clique rápido: Cadastra novo jogador.
  • Clique longo: Gerencia, edita e exclui jogadores existentes.
2 Jogador na Tabela
  • Clique no nome: Seleciona para a partida.
  • Sistema verifica se a dupla já jogou na semana atual.
3 Posição do Jogador
  • Clique no número amarelo da posição para editar o nome direto na tabela.
4 Painel de Ranking
  • Ordenação automática por Pontos.
  • Ícone de câmera exposto para compartilhar imagem do Ranking.
5 Botão Histórico
  • Clique rápido: Exibe/oculta o histórico.
  • Use o seletor para filtrar por jogador e o ✕ para desfazer um jogo (pede senha).
  • Clique longo: Abre o painel de Backup, Exportação e Restauração TXT.
6 Botão Semana
  • Clique rápido: Mostra jogos da semana (encerra sozinha toda segunda-feira).
  • Clique longo: Abre este Mini Manual.
7 Slots Jogador 1 e 2
  • Exibe jogadores selecionados.
  • Clique no slot para remover jogador.
8 Botão Confirmar
  • Valida os placares permitidos.
  • Exige confirmação dupla para salvar.
